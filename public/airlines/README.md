Drop airline logo files here named by IATA code (e.g. `DL.svg`, `AA.svg`, `UA.svg`).
Then add the code to `AIRLINE_LOGO_FILES` in `src/data/airline-logos.ts`; the
`AirlineLogo` component only requests files listed there and otherwise renders a
generated brand-colour mark. Airline logos are
trademarks of their owners; use them only under the airline's brand guidelines
or your commercial agreement with them.
