Drop airline logo files here named by IATA code (e.g. `DL.svg`, `AA.svg`, `UA.svg`).
The `AirlineLogo` component looks for `/airlines/{IATA}.svg` and falls back to a
generated brand-colour mark when the file is missing. Airline logos are
trademarks of their owners; use them only under the airline's brand guidelines
or your commercial agreement with them.
